JARVIS Browser Agent 3.5.0

Install in Chrome, Edge, or Brave:
1. Extract this ZIP file.
2. Open the browser's Extensions page and enable Developer mode.
3. Choose "Load unpacked" and select the extracted folder.
4. Click the JARVIS toolbar button. It is connected to the JARVIS API; no site URL is needed. NVIDIA chat works without a token. If Claude or OpenRouter are protected by `JARVIS_ACCESS_TOKEN`, enter that access token in the password field. Never enter a provider API key.
5. Open a regular website and click the orb or press Alt+J. Allow microphone or camera access only if you want those controls.

The extension runs separately from the JARVIS website. Click Wake JARVIS to inject into the current website, including existing tabs. For automatic access on every site, use the popup's site access button and choose “On all sites”; refresh tabs after updating. Common browser commands, voice-label clicks, and screen-region clicks run locally; complex tasks use the extension API. Hand controls offer index-thumb left click, middle-thumb page context click, ring-thumb double-click, V-sign scroll, pinch-drag scroll, and an air keyboard. Chrome protected pages such as chrome:// settings, the Chrome Web Store, and the built-in PDF viewer do not allow content scripts.
